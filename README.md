# Miquel Lopez Escoriza - Personal Homepage

Static GitHub Pages site generated from the CV in this directory.

## Publish

1. Create or use the repository `MIQUEL-LOPEZ-ESCORIZA.github.io`.
2. Put these files at the repository root.
3. Push to the default branch.
4. In GitHub repository settings, enable Pages from the default branch root if it is not already enabled.

The page entry point is `index.html`, and the downloadable CV is `cv.pdf`.
